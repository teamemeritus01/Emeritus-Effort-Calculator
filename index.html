Pure Talk Time = Duration only if Dialer Connected

📅 Week-on-Week Comparison
📌 How to read it: For each advisor, it shows their numbers for your selected dates vs the same number of previous dates from stored history.
📌 Arrows mean: ↑ Green = doing better than before · ↓ Red = doing worse · → Grey = roughly the same (within 2%)
📌 Example: You select 08-May. The comparison column shows 07-May's data. If Sonal had 12 connected calls on 07-May and 15 on 08-May, you'll see ↑ 25%.
